# QQ AI Groupmate — 产品需求文档

**版本：** v0.1（初始草案）

**项目状态：** 需求设计阶段

## 1. 项目愿景

QQ AI Groupmate 是一个以拟人化社交体验为核心的 QQ AI 群友项目。

项目的目标不是开发传统的指令式 QQ 机器人，而是创造一个具有稳定人格、长期记忆、社交关系与自主互动能力的 AI 群成员。

希望用户在长期相处中，能够感受到它作为一位独特群友的持续存在。

## 2. 核心设计原则

- **人格一致性：** AI 应具有独特、可配置且长期稳定的人格。
- **自然参与：** AI 能够理解群聊上下文，自主判断何时参与或保持沉默。
- **长期记忆：** AI 能够记住重要的人、事件、关系以及共同经历。
- **社交连续性：** AI 的互动应体现过去交流所形成的关系和上下文。
- **低打扰性：** 避免过度发言、机械式回复和无意义刷屏。
- **真实性与透明性：** AI 可以拟人化表达，但不应隐瞒其 AI 身份。

## 3. 第一阶段核心功能

### 3.1 群聊交互

支持多种聊天触发机制，包括：

- @AI 群友
- 提及 AI 的名字
- 群内戳一戳
- 根据群消息和上下文自主判断是否参与
- 在合适的连续对话窗口内继续交流

具体触发规则参考项目 workbuddy-qq-agent-gateway，并在开发过程中细化。

### 3.2 AI 人格系统

支持自定义角色人设、语言风格、行为倾向、角色背景和对话示例。

### 3.3 记忆系统

支持短期聊天上下文，以及经过筛选的长期记忆，包括群成员、重要事件、共同经历和社交关系。

记忆的存储、使用和删除应具有明确规则。

### 3.4 自主互动系统

AI 根据群聊活跃度、话题相关性、最近互动记录等因素决定是否参与。

自主发言需要频率限制、冷却机制与管理员控制。

### 3.5 QQ 空间社交互动系统（核心功能目标）

AI 群友不仅存在于群聊中，还应通过 QQ 空间展示其持续的社交活动。

#### 动态发布
- 支持 AI 根据人格、近期经历、记忆和时间生成说说。
- 支持自主发布、定时发布和人工触发发布。
- 动态内容应符合角色语言风格，避免机械重复。
- 后续支持发布图片等多媒体内容。

#### 动态互动
- 在授权范围内读取其他用户的空间动态。
- 根据动态内容与人物关系，自主判断是否评论或点赞。
- 支持回复 AI 自己发布的动态下的评论。
- 避免重复评论、连续刷屏和不合适的互动。

#### 自主行为与安全
- 支持关闭或开启自主发布与评论。
- 支持发布频率限制、冷却时间和每日操作上限。
- 开发初期采用人工审核发布模式，验证稳定后允许配置自动互动。
- 记录动态发布、评论和点赞的操作历史。
- 遵守 QQ 平台规则，保护其他用户的隐私。

#### 技术约束
QQ 空间自动发布、评论、点赞等功能依赖实际可用的 QQ 接入接口。

正式实现前必须验证接口可用性、权限、账号风险及稳定性。未通过验证的功能应明确标记，不得假定能够正常运行。

## 4. 后续扩展功能

- 更丰富的角色成长与社交关系系统
- 群消息整理、日报和自定义报告
- 可视化配置与管理功能

## 5. 交付目标

- 使用 Python 开发，优先复用成熟、可维护的开源组件。
- 由项目维护者部署在云服务器，收礼人直接在 QQ 中使用。
- 支持持续运行、日志记录、故障恢复和模型配置。
- 以 GitHub 仓库管理源码、文档与版本。
- 妥善保护 API 密钥、QQ 凭证和群聊隐私数据。

- 自主发言的判断机制
- 长期记忆与社交关系的演化规则
- QQ 空间功能的具体行为
- 管理员权限和隐私边界
- 不同功能阶段的验收标准
